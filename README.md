### Responsive Design

The website is designed to work across:

- Desktop
- Laptop
- Tablet
- Mobile

Includes a responsive mobile navigation menu with:

- Hamburger menu
- Open / close animation
- Active navigation state
- Automatic menu closing after navigation

Navigation links connect directly to website sections:

- Home
- Services
- Work
- Process
- About
- Pricing
- Contact

The website includes a project enquiry form with:

- Name
- Email
- Business / Company
- Service
- Project Budget
- Project Details
